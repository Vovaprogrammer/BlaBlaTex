# Бенчмарк LLM-провайдеров

Конфигурация содержит список провайдеров: `name`, `base_url`, `model`,
`api_key_env` (имя переменной окружения). Значения ключей в конфигурацию
не записываются. Необязательные `input_price` и `output_price` задаются парой
в USD за миллион токенов. Для примера см. `providers.example.json`.

HTTPS обязателен для внешних адресов; HTTP разрешён только для локального
сервера. Запуск и измерение моделей добавляются следующим изменением.
