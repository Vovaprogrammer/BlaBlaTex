## 📋 О проекте

BlaBlaTex — это современный онлайн-редактор LaTeX, который использует локальные AI модели для помощи в написании научных и технических документов. Проект полностью бесплатен и работает локально на вашем компьютере.

### Ключевые возможности

- ✍️ **Редактор LaTeX** с подсветкой синтаксиса и автодополнением
- 🤖 **AI Ассистент** на базе Gemma 4
- 📄 **Предпросмотр PDF** в реальном времени
- 🔧 **Автоисправление** ошибок компиляции
- 📊 **Генерация таблиц** и диаграмм
- 📚 **Библиография** по DOI/arXiv
- 👥 **Совместная работа** над документами

## 🚀 Быстрый старт

### 1. Установите Docker Desktop

Скачайте и установите Docker Desktop с официального сайта:  
👉 https://www.docker.com/products/docker-desktop/

Запускайте файл установщика от имени администратора.

### 2. Клонируйте репозиторий

```bash
git clone -b develop https://github.com/Vovaprogrammer/BlaBlaTex.git
cd BlaBlaTex
```

### 3. Настройте переменные окружения

Скопируйте файл .env.example в .env и заполните своими данными:

```bash
cp .env.example .env
```

Что нужно заполнить:

SECRET_KEY — необходимо получить у доверенного лица и вставить в .env

### 4. Скачайте AI модель Gemma 4

🔗 [google_gemma-4-E4B-it-Q4_K_M.gguf](https://huggingface.co/bartowski/google_gemma-4-E4B-it-GGUF/resolve/main/google_gemma-4-E4B-it-Q4_K_M.gguf)

Поместите скачанный файл в папку:  
   
`BlaBlaTex/ollama-models/gemma4/`

### 5. Запустите проект

```bash
docker compose up -d
```

### 6. Откройте в браузере

```
http://localhost:5173
```

> 💡 **Первый запуск** может занять 30-40 минут (скачивание образов и зависимостей)  
> 🔄 **Последующие запуски** — 5-10 секунд

## 🤖 AI Assistant

В проекте используется модель **Google Gemma 4 E4B** — мощная языковая модель на 12 миллиардов параметров, оптимизированная для работы на потребительском оборудовании.

### ✨ Почему Gemma 4

- **Бесплатно и локально** — модель работает полностью на вашем компьютере через Ollama, не требуя доступа в интернет.
- **Качественная генерация LaTeX** — модель отлично справляется с созданием математических формул, таблиц и полноценных документов.
- **Поддержка русского языка** — Gemma 4 понимает запросы на русском и генерирует код с кириллическими комментариями.
- **Стабильная работа** — в отличие от других моделей, Gemma 4 не требует сложной настройки и работает предсказуемо.

### ⚙️ Технические требования

- **Минимум 16 ГБ оперативной памяти** (рекомендуется 32 ГБ).
- **Свободное место на диске:** ~5.5 ГБ для файла модели.
- **Процессор:** Современный CPU с поддержкой AVX2 инструкций.

### 📝 Использование

1. Откройте сайт и войдите в аккаунт.
2. В правой панели нажмите "AI Assistant".
3. Опишите, что вы хотите сгенерировать (например, "формула бинома Ньютона").
4. Нажмите "Generate LaTeX" и дождитесь результата.
5. Используйте кнопки "Copy" и "Insert" для работы с полученным кодом.

### 💡 Советы

- Чем точнее вы опишете задачу, тем качественнее будет результат.
- Модель работает быстрее, если запросы небольшие и конкретные.
- Для сложных математических выражений используйте английские термины.

Модель **Gemma 4 E4B** не входит в стандартную поставку Ollama, поэтому её нужно скачать отдельно. Скачивание модели занимает примерно 10 минут.

### Проверка (после запуска контейнеров)

```bash
docker exec blablatax-ollama ollama list
```

Должна появиться модель gemma4-e4b.
