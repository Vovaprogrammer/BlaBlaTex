# Требования к оформлению отчётов

По этому документу верстается общий класс `mtuci-report` (T1.2) и шаблон лабораторной `mtuci-lab` (T1.3). Из него же берутся правила для ИИ (`ai_rules`, `guide`) и проверки (T3.1). Методички открывать не нужно: всё, что из них нужно, — здесь.

Правила для ВКР — [vkr.md](vkr.md), для презентаций — [slides.md](slides.md).

## Главное решение

**Все учебные отчёты (лабораторные, практические, курсовые, по практике) оформляются по методичке МТУСИ по ВКР бакалавра.** Решение команды от 2026-11-09. Правила оформления у вуза есть только для ВКР, и они не менялись с 2021 года.

**Стиль один на весь вуз.** Вариантов под кафедры и преподавателей нет. Шаблон лабораторной тоже один на все предметы, дисциплину вводит студент. Вуз заранее не спрашиваем: делаем так, а если поправят — меняем общий стиль сразу для всех (раздел 12).

Порядок источников:
1. **МВКР** — методичка МТУСИ по ВКР бакалавра (ниже — «Источники»). Пункт указан, например «МВКР 7.3».
2. **ГОСТ 7.32** — ГОСТ 7.32-2017 «Отчёт о научно-исследовательской работе». Берётся только там, где МВКР молчит. Сама МВКР ссылается на старый ГОСТ 7.32-2001 и ГОСТ 2.105-95.
3. **Решение** — правила нет ни в МВКР, ни в ГОСТ, или его буква даёт нелепый результат. Решение команды; до пилота можно менять.
4. **Толкование** — правило в МВКР есть, но сформулировано неточно. Записано, как мы его понимаем.

Значения ГОСТ 7.32-2017 и fixstudent.ru, которые расходятся с МВКР (например, поля 30/15/20/20), **не используются**.

| Шрифт | Times New Roman 14 pt. У нас — Liberation Serif 14 pt: метрики совпадают с Times New Roman | МВКР 7.3; `architecture.md` 6 |

| Межстрочный интервал | полуторный | МВКР 7.3 |
| Сколько строк на странице | 29–31 строка сплошного текста | МВКР 7.3 |
| Выравнивание | по ширине | МВКР 7.3 («по левому и правому полям») |
| Абзацный отступ | 1,25 см, одинаковый везде, в том числе у первого абзаца после заголовка | МВКР 7.3 |
| Отступы между абзацами | нет | Решение |
| Переносы слов | включены, по правилам русского языка | Решение |

**Как получить полуторный интервал в LaTeX (толкование).** В Word «1,5 строки» для Times New Roman 14 pt — это шаг строк ≈ 24,15 pt (14 × 1,15 × 1,5). Высота текста на странице — 297 − 20 − 25 = 252 мм ≈ 714 pt, то есть ≈ 29,6 строки. Это и есть «29–31 строка» из МВКР. Проверка класса: на странице сплошного текста 29–30 строк.

## 2. Заголовки и структура

| Что | Значение | Источник |
|---|---|---|
| Заголовки без номера: СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ, СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ | прописными, полужирные, 14 pt, по центру, без точки в конце | МВКР 7.3 (полужирный 14 pt); остальное — ГОСТ 7.32 |
| Разделы | `1 Цель работы`: номер арабской цифрой без точки после него, с абзацного отступа, с прописной буквы, полужирные, 14 pt, без точки в конце | МВКР 7.3 (полужирный 14 pt); остальное — ГОСТ 7.32 |
| Подразделы | `3.1 Название` — оформление как у разделов | МВКР 7.3; ГОСТ 7.32 |
| Глубина | не больше трёх уровней (`3.1.2`) | Решение |
| Отбивка заголовка | между заголовком раздела и текстом — «три интервала», столько же между заголовками раздела и подраздела | МВКР 7.3 |
| Новая страница | каждый раздел, введение, заключение, список источников и каждое приложение начинаются с новой страницы | МВКР 7.4 |
| Содержание | есть в ВКР, курсовой и отчёте по практике; в лабораторной и практической работе — нет | МВКР 6.2; методичка по практике 3.16.3; для лабораторной — Решение |

**«Три интервала» (толкование).** Отбивка — три одинарные строки шрифта 14 pt, то есть ≈ 48 pt (≈ 17 мм), над текстом после заголовка и между заголовками раздела и подраздела. Перед заголовком раздела, который начинается не с новой страницы, — такая же отбивка.

**Исключение для лабораторных и практических работ (решение).** Их разделы («Цель работы», «Задание», «Ход работы», «Выводы») идут подряд, а не каждый с новой страницы. Иначе отчёт на 3–4 страницы растянется на 6–8 листов с короткими разделами. С новой страницы начинаются только список источников и приложения.

## 7. Листинги кода

Ни МВКР, ни ГОСТ 7.32 листинги не описывают. Всё в этом разделе — **решение**; если преподаватели против — меняем до пилота.

| Что | Значение |
|---|---|
| Подпись | над листингом, слева, без абзацного отступа, как у таблиц: `Листинг 3.1 – Название` |
| Номер | в пределах раздела, как у рисунков; в приложении — `Листинг А.1` |
| Шрифт | Liberation Mono 12 pt, одинарный интервал, без абзацного отступа |
| Длинные строки | переносятся, а не обрезаются. Кириллица в комментариях и строках выводится |
| Номера строк, рамка, фон | нет: отчёты печатают чёрно-белыми |
| Ссылка в тексте | обязательна: «в листинге 3.1» |
| Объём в тексте | до ~40 строк (около страницы) — главные фрагменты. Код длиннее — целиком в приложение, а в тексте — ссылка на него. Основа: МВКР 6.3 — вспомогательные материалы выносятся в приложение |

Макросы — из `architecture.md` 9.6: `\bbtDepartment`, `\bbtGroup`, `\bbtShortName`, `\bbtDiscipline`, `\bbtCity`, `\bbtYear` — встроенные; `\bbtLabNumber`, `\bbtLabTitle`, `\bbtVariant`, `\bbtTeacher`, `\bbtWorkType` — поля шаблона (`template.yaml`, T1.3). Строку под «ОТЧЕТ» класс выбирает по полю `work_type` (решение 2026-11-09): «Практическая работа» — «по практической работе», любое другое значение или пустое поле — «по лабораторной работе». Других форм слов класс не строит. Значение `\bbtDiscipline` вводит студент: шаблон один на все предметы (T1.3).

## 12. Что могут поправить

Ничего из этого вуз заранее не подтверждал. Поправку вносим здесь и в классе — сразу для всех отчётов.

Поправки лучше собрать до запуска, на пилоте (T3.2). После запуска смена стиля меняет вид уже сделанных отчётов: студент пересоберёт старую работу и получит другой PDF.

| Наше решение | Что могут сказать |
|---|---|
| Лабораторные — по правилам ВКР | нужны поля ГОСТ 7.32-2017 (30/15/20/20) или сквозная нумерация рисунков |
| Титульник лабораторной собран нами | другие формулировки или порядок строк, «Выполнил / Проверил» вместо «Студент / Преподаватель» |
| Кафедра на титульнике — из профиля студента | нужна кафедра, которая ведёт предмет |
| Листинги — по разделу 7 | код только в приложении или с номерами строк |
| Разделы лабораторной — подряд | каждый раздел с новой страницы, как в ВКР |

Филиалы МТУСИ (Ростов-на-Дону, Нижний Новгород) пишут свои правила: например, в методичке СКФ по практике поля 30/15/20/20 и сквозная нумерация рисунков. Сервис пока делает отчёты по правилам головного вуза (Москва).
