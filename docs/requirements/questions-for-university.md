# Вопросы вузу: оформление отчётов и размещение сервиса

От ответов на эти вопросы зависит, как сервис оформляет отчёты и какие будут шаблоны предметов. Без них первые шаблоны не начать.

Как пользоваться:
- Ответы вписывайте в колонку «Ответ».
- Документы, методички, образцы и отчёты кладите в закрытую папку команды. Отчёты — только без ФИО и групп.
- В колонке «Зачем нам» объяснено, что поменяется в сервисе от ответа. Если ответ неожиданный — это и есть самое важное.

> **Отложено (2026-11-09).** Вуз заранее не спрашиваем. Правила оформления у МТУСИ есть только для ВКР — по ним делаем все шаблоны, один стиль на весь вуз. Если вуз или преподаватели поправят — меняем. Что решено — в [report-formatting.md](report-formatting.md), [vkr.md](vkr.md) и [slides.md](slides.md).
>
> Список ниже пригодится позже — к пилоту (T3.2) и к ВКР. Ответ на вопросы 1.1, 1.3, 2.1–2.5, 2.7, 2.8, 2.11, 2.13–2.15, 3.2, 3.9, 5.4 и 8.1 уже есть в методичке или в решениях команды.

> **Размещение (2026-11-13).** Своего сервера у команды нет: сервис передаётся вузу — в личный кабинет МТУСИ, на его серверы ([ADR 0003](../adr/0003-hosting-target.md)). Вопросы раздела 9 нужно задать до передачи. Главный — 9.1: от него зависит, смогут ли студенты работать через своего ИИ-агента.

## С чего начать

Если встреча одна и короткая, сначала задайте эти 7 вопросов. От них зависит, как устроены все шаблоны:

1. **1.4** — подходит ли для лабораторных оформление по методичке ВКР (поля 30/10/20/25 мм, нумерация рисунков по разделам).
2. **1.2** — есть ли у кафедр свои требования сверх методички.
3. **3.3** — какую кафедру пишут на титульном листе: предмета или студента.
4. **3.5** — как на титульном листе указывают преподавателя.
5. **4.1** — с каких трёх предметов начинать.
6. **5.1** — в каком виде сдают отчёт: PDF, Word или распечатка.
7. **6.1** — есть ли правила об использовании ИИ в учебных работах.

## 1. Один стиль или разный

Кого спросить: учебно-методическое управление или деканат, заведующих кафедрами.

| № | Вопрос | Зачем нам | Ответ |
|---|---|---|---|
| 1.1 | Есть ли в МТУСИ общий документ о том, как оформлять студенческие работы: положение, стандарт вуза, методичка по оформлению? Попросить файл и дату утверждения. | Если есть — делаем один стиль для всех отчётов, а шаблоны предметов отличаются только разделами и титульным листом. | |
| 1.2 | Если общего документа нет — правила задаёт кафедра или каждый преподаватель сам? Сколько кафедр со своими требованиями? | Решаем, настраивать оформление под кафедру или под каждого преподавателя. Чем мельче деление, тем больше шаблонов и работы. | |
| 1.3 | Если в требованиях о чём-то не сказано, примут ли отчёт, оформленный по ГОСТ 7.32-2017 («Отчёт о НИР»)? | ГОСТ — наш вариант по умолчанию для всего, что вуз не задаёт. | |
| 1.4 | Отличаются ли требования у лабораторной, практической, курсовой работы и отчёта по практике? | Один шаблон на предмет или отдельный на каждый вид работы. | |
| 1.5 | Как часто меняются требования: каждый учебный год, при смене преподавателя? Кто сообщает об изменениях? | Шаблоны придётся обновлять — нужно знать, как часто и откуда узнавать. | |

## 2. Оформление текста, рисунков, таблиц и кода

Кого спросить: если общего документа нет — кафедру или преподавателя. Нужны точные значения: из них собирается общий стиль всех отчётов.

| № | Вопрос | Зачем нам | Ответ |
|---|---|---|---|
| 2.1 | Поля страницы: левое, правое, верхнее, нижнее (в мм). | Основа стиля. | |
| 2.2 | Шрифт и размер. Нужен строго Times New Roman или подойдёт шрифт, который по размерам совпадает с ним и на глаз почти не отличается? | У нас Liberation Serif — по размерам он совпадает с Times New Roman. Если нужен именно Times, придётся искать лицензию. | |
| 2.3 | Межстрочный интервал, абзацный отступ, выравнивание по ширине, переносы слов. | Основа стиля. | |
| 2.4 | Номера страниц: где стоят, с какой страницы начинаются, есть ли номер на титульном листе. | Основа стиля. | |
| 2.5 | Заголовки разделов: нумерация (1, 1.1), жирный или обычный, заглавными буквами, по центру или слева, каждый ли раздел с новой страницы. | Основа стиля. | |
| 2.6 | Нужно ли содержание (оглавление) в отчёте по лабораторной? | Если нужно — сервис добавит его сам. | |
| 2.7 | Рисунки и скриншоты: подпись «Рисунок 1 — …» под рисунком? Нумерация сквозная (1, 2, 3) или по разделам (1.1, 1.2)? Обязательна ли ссылка на рисунок в тексте? | Сервис ставит подписи и номера сам — нужен точный формат. | |
| 2.8 | Таблицы: подпись «Таблица 1 — …» над таблицей — слева или по центру? Как переносить таблицу на следующую страницу? | То же, что у рисунков. | |
| 2.9 | Код: можно ли вставлять код в текст отчёта или только в приложение? Нужны ли подпись «Листинг 1 — …», номера строк, особый шрифт? | ИИ вставляет код из материалов студента — должен знать, куда и как. | |
| 2.10 | Код вставлять целиком или только главные фрагменты? Есть ли предел длины? | Правило для ИИ: сколько кода класть в отчёт. | |
| 2.11 | Формулы: номер справа в скобках? Пояснение «где …» после формулы? | Основа стиля. | |
| 2.12 | Списки: какие маркеры (тире, буквы, цифры), какие знаки в конце пунктов. | Основа стиля. | |
| 2.13 | Нужен ли список источников в отчёте по лабораторной? По какому ГОСТ (Р 7.0.100-2018 или 7.1-2003)? Как ссылаться в тексте — [1]? | Если нужен — ИИ должен ссылаться только на источники из материалов. | |
| 2.14 | Приложения: когда нужны, как оформляются («Приложение А»)? | Туда может уходить длинный код. | |
| 2.15 | Можно ли цветные скриншоты и схемы или отчёт печатают чёрно-белым? | При чёрно-белой печати тёмные скриншоты (тёмная тема редактора) нечитаемы — сервис будет об этом предупреждать. | |

## 3. Титульный лист

Кого спросить: кафедру и преподавателей. Титульный лист сервис собирает сам из профиля студента и данных проекта, поэтому нужен точный образец.

| № | Вопрос | Зачем нам | Ответ |
|---|---|---|---|
| 3.1 | Попросить образец титульного листа в Word для каждой кафедры (можно с вымышленным студентом). | По нему верстаем титульный лист один в один. | |
| 3.2 | Верх листа: точное полное название вуза, нужна ли строка министерства, нужен ли логотип? | Логотип — картинка в шаблоне: нужны файл и разрешение (вопрос 7.4). | |
| 3.3 | Какую кафедру пишут на титульном листе: кафедру, которая ведёт предмет, или кафедру студента? | Сейчас кафедру студент вводит в профиле. Если нужна кафедра предмета — берём её из шаблона, и студенту её вводить не надо. | |
| 3.4 | Что ещё указывать о студенте: факультет, курс, направление подготовки (код и название), профиль, форму обучения? | Каждое новое поле — новый вопрос в профиле студента. | |
| 3.5 | Как указывать преподавателя: ФИО, должность, учёная степень («доц., к.т.н.»)? Слово «Проверил» или «Принял»? Нужны ли места для подписи, даты, оценки? | Если у предмета один преподаватель — пишем его в шаблон, студенту не вводить. Если несколько — студент выбирает или вводит сам. | |
| 3.6 | Как указывать студента: «Выполнил: студент группы БВТ2401 Иванов И. И.»? Точный порядок слов и сокращения. | Строка собирается автоматически из профиля. | |
| 3.7 | Точная формулировка названия работы, например: «Отчёт по лабораторной работе № 3 по дисциплине "…" на тему "…"». | Тоже собирается автоматически. | |
| 3.8 | Пишут ли вариант на титульном листе? Как студент узнаёт свой вариант? | Нужно ли поле «Вариант» в проекте. | |
| 3.9 | Внизу листа «Москва 2026» — так или иначе? | Основа титульного листа. | |
| 3.10 | Нужна ли после титульного листа ещё страница: задание, аннотация? | Если нужна — она войдёт в шаблон. | |

## 4. Предметы и содержание отчётов

Кого спросить: преподавателей первых трёх предметов. Предложение для первых шаблонов — СиАОД, ИТиП (Java) и МОБД (PostgreSQL); вопросы 4.2–4.12 задать по каждому.

| № | Вопрос | Зачем нам | Ответ |
|---|---|---|---|
| 4.1 | С каких трёх предметов начать: где больше всего лабораторных и студентам тяжелее всего с отчётами? ФИО преподавателя, курс, семестр. | Это первые шаблоны сервиса. | |
| 4.2 | Сколько лабораторных в семестре? У всех одинаковая структура отчёта или у каждой своя? | Один шаблон на предмет или на каждую работу. | |
| 4.3 | Какие разделы обязательны и в каком порядке: цель, задание, теория, ход работы, результаты, выводы, ответы на контрольные вопросы, список источников, приложения? | Это разделы шаблона — ИИ заполняет их по порядку. | |
| 4.4 | Нужна ли теория в отчёте? Можно ли пересказать её из методички или за это снижают оценку? | Правило для ИИ: писать теорию или нет. | |
| 4.5 | Нужны ли в отчёте ответы на контрольные вопросы? | Ещё один раздел шаблона. | |
| 4.6 | Скриншоты: что на них должно быть (результат программы, весь экран, ФИО или дата в окне)? Сколько примерно? | Подсказка студенту, какие скриншоты загрузить. | |
| 4.7 | Код: весь или только изменённые части? Обязательны ли комментарии в коде? | Правило для ИИ. | |
| 4.8 | Что ждут в выводах: ответ на цель работы, числа, сравнение? | Правило для ИИ. | |
| 4.9 | Есть ли требования к объёму отчёта (минимум и максимум страниц)? | Правило для ИИ. | |
| 4.10 | Что преподаватель проверяет в первую очередь? За что чаще всего снижает оценку или возвращает отчёт? | Эти ошибки сервис будет ловить сам до сдачи. | |
| 4.11 | Можно ли получить методички и задания в электронном виде? | На них проверяем, как ИИ пишет отчёты. В открытый доступ не выкладываем. | |
| 4.12 | Есть ли 2–3 хороших отчёта прошлых лет (без ФИО), которые преподаватель считает образцом? | Эталон: с ним сравниваем отчёты сервиса. | |

## 5. Как сдают отчёт

Кого спросить: преподавателей, деканат.

| № | Вопрос | Зачем нам | Ответ |
|---|---|---|---|
| 5.1 | В каком виде сдают: распечатка, PDF или Word? Куда: в ЛМС, на почту, лично? | Сервис выдаёт PDF. Если обязательно Word — нужна выгрузка в Word, это большая отдельная работа. | |
| 5.2 | Нужна ли подпись студента: от руки на распечатке или электронная? | Нужно ли место для подписи на титульном листе. | |

| 5.4 | Печатают на одной стороне листа или на обеих? | При печати на обеих сторонах поля чередуются — это настройка стиля. | |

## 9. Размещение на серверах МТУСИ

Кого спросить: управление информатизации или администраторов личного кабинета. Подробности — в [ADR 0003](../adr/0003-hosting-target.md).

| № | Вопрос | Зачем нам | Ответ |
|---|---|---|---|
| 9.1 | Сайт и личный кабинет МТУСИ открываются только с российских адресов. Можно ли открыть адрес BlaBlaTex для запросов из любых стран — только его, а не весь сайт вуза? | Большинство студентов будут работать через своего ИИ-агента (Claude Code, Codex, Cursor). Агенту из России обычно нужен VPN, а программа BlaBlaTex, которую агент запускает на компьютере студента, ходит на сервер вуза через тот же VPN. При блоке по стране сервер ей откажет, и агент не сможет ни прочитать файлы проекта, ни собрать PDF. Защиты блок здесь не добавляет: без личного токена студента сервер BlaBlaTex и так никого не пускает. | |
| 9.2 | Будет ли у сервера выход в интернет к API провайдера ИИ (например, Yandex AI Studio или GigaChat)? | Без него не работает ИИ в чате на сайте. Работа через агента студента от этого не зависит: там текст пишет сам агент. | |
| 9.3 | Что нужно для размещения: ОС, Docker, домен и HTTPS? Кто делает бэкапы и обновления? | Под это готовим пакет для администраторов вуза: готовые образы, настройки и инструкцию. | |
| 9.4 | Входить в сервис через учётную запись личного кабинета или своей почтой и паролем? | Вход через личный кабинет — отдельная доработка: нужно знать, как устроены учётные записи вуза. | |
| 9.5 | Кто оператор персональных данных — вуз или команда? Кто подаёт уведомление в Роскомнадзор? | От этого зависит текст согласия при регистрации (T3.3). | |
