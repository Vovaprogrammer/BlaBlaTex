# Лабораторная работа 4. Синтез комбинационной схемы сравнения

Вымышленное задание для эталонного отчёта BlaBlaTex.

## Цель работы

Освоить синтез комбинационной схемы по таблице истинности: запись совершенной дизъюнктивной нормальной формы, минимизацию по карте Карно и проверку схемы в Logisim.

## Задание

1. Составить таблицу истинности функции F, равной 1, если двухразрядное число A = a1a0 больше числа B = b1b0.
2. Записать совершенную дизъюнктивную нормальную форму (СДНФ) функции F.
3. Минимизировать функцию по карте Карно и записать минимальную ДНФ.
4. Построить схему по минимальной ДНФ в Logisim на элементах И, ИЛИ, НЕ.
5. Проверить схему тестовыми векторами на всех 16 наборах входов.

## Содержание отчёта

Краткие теоретические сведения (СДНФ, карта Карно), таблица истинности, СДНФ, карта Карно с контурами, минимальная ДНФ, схема, результат проверки.
