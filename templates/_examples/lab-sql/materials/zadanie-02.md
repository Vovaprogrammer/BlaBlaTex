# Лабораторная работа 2. Запросы SELECT к реляционной базе данных

Вымышленное задание для эталонного отчёта BlaBlaTex.

## Цель работы

Научиться создавать связанные таблицы и составлять запросы на выборку с сортировкой, соединением таблиц, группировкой и вложенными запросами.

## Задание

1. Создать в SQLite базу данных библиотеки из трёх таблиц — читатели, книги, выдачи — с первичными и внешними ключами и заполнить её тестовыми данными. Привести схему базы данных.
2. Составить запрос с условием и сортировкой: книги одного автора, новые сначала.
3. Составить запрос с соединением таблиц: книги, которые сейчас на руках, с именами читателей и сроками возврата.
4. Составить запрос с группировкой: сколько раз каждый читатель брал книги, только читатели с несколькими выдачами.
5. Составить запрос с вычислением: просроченные выдачи на дату проверки и число дней просрочки.
6. Составить вложенный запрос: книги, которые ни разу не выдавались.

## Содержание отчёта

Для каждого запроса — текст запроса, результат выполнения и пояснение, почему результат именно такой.
