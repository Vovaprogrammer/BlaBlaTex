\section{Выводы}
Создана база данных библиотеки из трёх связанных таблиц, и к ней составлены пять запросов:
с условием и сортировкой, с соединением, с группировкой, с вычислением и вложенный. Все
запросы выполнены в SQLite, их результаты согласуются с тестовыми данными.

Разбор результатов показал, что обычное соединение отбрасывает читателей без выдач, поэтому
для отчёта по всем читателям нужен \texttt{LEFT JOIN}, а \texttt{NOT IN} безопасен только
для столбца без пустых значений.
