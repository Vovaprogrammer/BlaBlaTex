# Лабораторная работа 5. Алгоритмы поиска подстроки

Вымышленное задание для эталонного отчёта BlaBlaTex.

## Цель работы

Изучить наивный алгоритм поиска подстроки и алгоритм Кнута — Морриса — Пратта, экспериментально сравнить их время работы на разных классах входных данных и сопоставить результат с теоретическими оценками сложности.

## Задание

1. Реализовать наивный поиск всех вхождений образца в текст со счётчиком сравнений символов.
2. Реализовать вычисление префикс-функции и поиск по алгоритму Кнута — Морриса — Пратта (КМП) со счётчиком сравнений.
3. Сгенерировать по seed варианта (100 + номер варианта) два класса входов — случайный текст над алфавитом из четырёх букв и худший для наивного поиска случай — для пяти длин текста с шагом 2; длина образца — n/20. Выполнить замеры: прогрев, пять повторов, медиана.
4. Построить график времени от длины текста в логарифмических осях, сопоставить рост времени с оценками O(n·m) и O(n + m), объяснить разницу между классами входов.
5. Проверить корректность: сверка с поиском встроенными средствами языка на нескольких сотнях случайных входов и граничные случаи — пустой текст, образец длиннее текста, перекрывающиеся вхождения.

## Содержание отчёта

Цель, задание, ход работы по пунктам задания с фрагментами кода, таблицы замеров и счётчиков сравнений, график, выводы. Ответы на контрольные вопросы включаются в отчёт.

## Контрольные вопросы

1. Почему наивный поиск на случайном тексте работает почти линейно, хотя его оценка в худшем случае — O(n·m)?
2. Что хранит префикс-функция и почему КМП никогда не возвращается назад по тексту?
3. На каких входах КМП заметно выигрывает у наивного алгоритма, а на каких — нет?
