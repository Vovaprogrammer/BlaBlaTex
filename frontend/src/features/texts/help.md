# Отчёт за 5 минут

Вы загружаете методичку, код и скриншоты, ИИ-помощник пишет отчёт, а BlaBlaTex собирает PDF, оформленный по требованиям вуза. Знать LaTeX не нужно.

## 1. Заполните профиль

После регистрации откроется «Профиль». Заполните фамилию, имя, отчество, группу, факультет и кафедру и нажмите «Сохранить изменения». Эти данные попадут на титульный лист всех ваших отчётов.

Поменять их можно в любой момент: «Профиль» → «Изменить профиль». В отчёте они обновятся после «Собрать PDF».

## 2. Создайте проект

«Проекты» → «Новый проект». Дальше четыре шага:

1. **Тип работы** — «Лабораторная».
2. **Шаблон** — шаблон лабораторной.
3. **Данные** — «Название проекта» нужно только для списка проектов. Дисциплина, номер и тема работы обязательны, вариант, преподаватель и вид работы — по желанию. Всё это попадёт на титульный лист.
4. **Материалы** — методичка или задание, код, скриншоты, данные. До 20 МБ на файл. Шаг можно пропустить и загрузить файлы потом.

Нажмите «Создать проект». Сайт откроет проект и сам напишет ИИ: «Сделай отчёт по загруженным материалам».

## 3. Пока ИИ работает

Ответ появляется в чате по мере того, как ИИ его пишет. Карточки в чате показывают, что он делает: читает материалы, правит файлы, собирает PDF. Пока ИИ работает, файлы проекта доступны только для чтения. Остановить его — кнопка «Остановить».

ИИ читает материалы после того, как сервер достанет из них текст. Чтобы увидеть, что именно читает ИИ, откройте материал в «Файлы» и нажмите «Текст для помощника».

ИИ не прочитает:

- PDF-скан без текста — загрузите текстовый PDF или документ Word;
- картинку SVG — сохраните её в PNG или JPG.

## 4. Получите PDF

Обычно ИИ сам собирает PDF, пока работает, и он появляется в панели «PDF». После своих правок нажмите «Собрать PDF». Скачать — «Скачать PDF».

Если сборка не удалась, под кнопкой появятся «Ошибки и предупреждения». Ссылка у ошибки открывает файл на нужной строке. Можно и просто попросить ИИ: «Исправь ошибки сборки».

## 5. Поправьте отчёт

- **Попросите в чате**, например: «Добавь в вывод сравнение времени сортировок» или «Сократи теорию до одного абзаца».
- **Посмотрите правки.** После ответа в чате появится карточка «Изменено файлов: N». «Посмотреть правки» покажет, что поменялось: зелёным — добавленное, красным — удалённое. Не понравилось — «Отменить правки» → «Подтвердить откат».
- **Поправьте сами.** Опечатку или слово можно исправить без ИИ: текст разделов лежит в «Файлы», в папке `sections`. Правки сохраняются сами.
- **Данные работы** (номер, вариант, преподаватель) меняются в меню проекта «⋯» → «Данные работы». Потом нажмите «Собрать PDF».

ИИ пишет только по вашим материалам. Если чего-то не хватает — например, вывода программы или скриншота результата, — добавьте это в материалы (скрепка в чате) и попросите дописать. Перед сдачей прочитайте отчёт целиком: ИИ может ошибиться.

## 6. Скачайте исходники

Меню проекта «⋯» → «Скачать исходники ZIP». Архив собирается и без BlaBlaTex, например в Overleaf: как это сделать, написано в файле «Как собрать.txt» внутри архива.

## Лимит ИИ

Сколько токенов ИИ осталось на сегодня, видно вверху страницы: «ИИ · Осталось N токенов». Лимит обновляется в полночь по Москве. Если он кончился, подождите до завтра или добавьте свой ключ: «Настройки» → «Ключ ИИ». Со своим ключом лимита нет, расход идёт на ваш аккаунт у провайдера ИИ.

## Свой ИИ-агент

Если вы работаете с ИИ-агентом — Claude Code, Codex, Cursor или другим, — он может работать с BlaBlaTex по личному токену.

1. «Настройки» → «Личные токены» → «Создать токен». Скопируйте токен сразу: потом его не посмотреть.
2. Готовый пакет для подключения агента ещё в работе, инструкция появится вместе с ним. Пока токен пригодится тем, кто пишет свои скрипты: [руководство по API](https://github.com/Vovaprogrammer/BlaBlaTex/blob/main/docs/api.md).

Токен даёт доступ ко всем вашим проектам. Когда он больше не нужен, нажмите «Отозвать». Удалить аккаунт, скачать архив проекта или поменять ключ ИИ по токену нельзя.

Как BlaBlaTex хранит ваши данные — в [политике конфиденциальности](/privacy).
